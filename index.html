Instructor setup: connect this form to Google Sheets

This page needs a free Google Apps Script "Web App" to act as the bridge to your Sheet. One-time setup, about five minutes:

  1. Create a new Google Sheet. Add a header row matching the field names in this form (e.g. Course, Term, Attendance, Pace, Clarity, ...) — or just let the script create headers automatically on first submit.
  2. In the Sheet, go to Extensions → Apps Script.
  3. Replace the default code with a script that reads e.parameter from the POST request and appends a row via SpreadsheetApp.getActiveSheet().appendRow(...).
  4. Click Deploy → New deployment → Web app. Set "Execute as: Me" and "Who has access: Anyone", then deploy and copy the resulting URL.
  5. In this HTML file, find the line const SCRIPT_URL = "PASTE_YOUR_APPS_SCRIPT_URL_HERE"; near the bottom and paste your URL in.

Once that's in place, every submission appears as a new row in your Sheet in real time. Pair this with results.html to see the responses plotted out.
